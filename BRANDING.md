## 2. Surface Modifiers


### Dark Mode

| Use Case | Base | Overlay |
|----------|------|---------|
| Window Background | Neutral 900 | - |
| Card / View Background | Neutral 900 | Neutral 50 @ 5% |
| Button Background | Neutral 900 | Neutral 50 @ 12% |
| Hover State | Neutral 900 | Neutral 50 @ 16% |
| Border | Neutral 900 | 1px Neutral 50 @ 12% |

### Light Mode

| Use Case | Base | Overlay |
|----------|------|---------|
| Window Background | Neutral 50 | Neutral 950 @ 3% |
| Card / View Background | Neutral 50 | Neutral 950 @ 2% |
| Button Background | Neutral 50 | Neutral 950 @ 5% |
| Hover State | Neutral 50 | Neutral 950 @ 8% |
| Border | Neutral 100 | 1px Neutral 950 @ 12% |
